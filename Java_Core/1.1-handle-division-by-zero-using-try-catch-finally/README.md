# Task : Handle Division by Zero Using try-catch-finally
## Description : 
Create a program that takes two integer inputs from the user and performs division. Implement error handling using try-catch blocks to handle the ArithmeticException when dividing by zero. Use a finally block to display a message indicating that the program execution has ended.
## Topics Covered : 
try, catch, finally Blocks, ArithmeticException
## Objective : 
Understand the basics of exception handling in Java and ensure program stability by catching runtime errors.
