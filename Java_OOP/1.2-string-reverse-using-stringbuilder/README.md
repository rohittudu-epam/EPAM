# Task : String Reverse using StringBuilder
## Description : 
- Write a program that accepts a sentence from the user and reverses the sentence using the StringBuilder class.
- Write a program to generate a formatted address by concatenating several input strings (e.g., street, city, state, postal code) using StringBuffer.

## Topics Covered : 
StringBuilder, StringBuffer
## Objective : 
- Learn how to use StringBuilder to perform operations like reversing strings efficiently.
- Understand the use of StringBuffer for dynamic string concatenation in scenarios requiring thread safety.

When to use StringBuilder & StringBuffer?
