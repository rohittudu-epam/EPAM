# Task : Dynamic Polymorphism in a Notification System
## Description : 
Create a Notification class with a method sendNotification(). Implement subclasses EmailNotification, SMSNotification, and PushNotification, overriding the method to provide specific notification mechanisms. Demonstrate dynamic polymorphism by invoking the method on various objects.
## Topics Covered : 
Polymorphism, Method Overriding, Abstraction
## Objective : 
Learn to implement dynamic polymorphism for real-world scenarios like a notification system.
