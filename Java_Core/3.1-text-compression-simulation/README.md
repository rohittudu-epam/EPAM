# Task : Text Compression Simulation
## Description : 
Create a program that compresses a given string by replacing consecutive duplicate characters with the character followed by its frequency (e.g., 'aabbcc' becomes 'a2b2c2'). Use StringBuilder for efficient manipulation.
## Topics Covered : 
StringBuilder, String Class and Methods
## Objective : 
Implement a real-world string manipulation task involving dynamic updates and efficient processing.
