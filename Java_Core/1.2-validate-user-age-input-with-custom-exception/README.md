# Task : Validate User Age Input with Custom Exception
## Description : 
Write a program that asks the user to input their age. If the age entered is less than 18, throw a custom exception called UnderAgeException. Catch this exception and display an appropriate message to the user.
## Topics Covered : 
throw, Custom Exceptions
## Objective : 
Learn how to define and use custom exceptions to validate user input and handle specific error scenarios.
