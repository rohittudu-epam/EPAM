# Task : File Reading with Checked Exception Handling
## Description : 
Develop a program to read a file specified by the user. Use a try-catch block to handle the FileNotFoundException and IOException. Add a finally block to ensure the file stream is closed, even if an exception occurs.
## Topics Covered : 
Checked Exceptions, try, catch, finally Blocks
## Objective : 
Gain an understanding of handling checked exceptions and ensuring resource cleanup using finally blocks.
