# Task : Detect and Handle Duplicate Strings
## Description : 
Write a program that takes a list of Strings as input. Identify duplicate strings based on their `hashCode` and `equals()` methods. Print all duplicates and ensure the program handles null values without throwing an exception.
## Topics Covered : 
hashcode & equals relation, string methods, null handling
## Objective : 
Understand the relationship between `hashCode` and `equals()` and how they can be used to detect duplicate strings.
