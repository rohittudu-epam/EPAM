# Task : Group Employees by Department Using Streams
 
 ## Description : 
 
 Create a list of Employee objects with attributes like name, salary, and department. Use Streams to group employees by their department and print the results.
 
 ## Topics Covered : 
 
 Streams API, Collectors, Grouping
 
 ## Objective : 
 
 Learn to group data using Streams' Collectors.
