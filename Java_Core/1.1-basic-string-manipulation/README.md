# Task : Basic String Manipulation
## Description : 
- Create a program that accepts a user's full name as input, splits it into first and last name, and displays both names in uppercase using the String class methods.
- Demonstrate the immutability of the String class by performing concatenation and verifying that a new String object is created.
## Topics Covered : 
- String Class and Methods
- String Immutability
## Objective : 
- Understand basic string manipulation using methods like split(), toUpperCase(), and trim().
- Understand the concept of string immutability and how new String objects are created after modifications.
