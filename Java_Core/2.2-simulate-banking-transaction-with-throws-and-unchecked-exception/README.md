# Task : Simulate Banking Transaction with throws and Unchecked Exception
## Description : 
Create a program simulating a banking transaction where users can withdraw money. If the withdrawal amount is greater than the account balance, throw an unchecked exception (e.g., IllegalArgumentException). Use a method that declares the throws keyword for potential exceptions.
## Topics Covered : 
throws, Unchecked Exceptions
## Objective : 
Learn how to declare exceptions using the throws keyword and handle runtime exceptions effectively.
